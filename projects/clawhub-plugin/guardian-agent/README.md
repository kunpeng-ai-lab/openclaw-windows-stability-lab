# Guardian Agent (OWSL)

> Maintained by: 鲲鹏 AI 探索局 / kunpeng-ai-lab  
> Official site: [kunpeng-ai.com](https://kunpeng-ai.com)

An AI-driven diagnostic agent for OpenClaw designed to live alongside `--doctor`. It performs deep environmental scans (Windows/Harness), auto-heals common issues, and provides a conversation interface for complex crashes.

## Scope
- **Windows Stability**: Process lock detection, proxy routing verification.
- **Auto-Heal**: Non-destructive repair of known failure cases.
- **Interactive Diagnostics**: Fallback to dialogue when automated fix is blocked.

## Development
This is a community plugin for [ClawHub](https://clawhub.ai/).
