# OWSL Stability Case Library

This directory stores reusable Windows stability cases produced by OWSL.

Each case should be usable by:

- humans reviewing OpenClaw Windows reliability work
- GA runtime/evidence adapters
- future skills and diagnostic rules
- upstream contribution planning

Case requirements:

- concrete symptom
- affected runtime surface
- evidence source
- reusable harness target or planned harness target
- decision rule
- GA capability mapping
- upstream status

Phase 2 minimum:

- at least 3 stability cases
- one case from the merged upstream PR
- two cases from Phase 2 harness checks
