# 04 Skills

Skill 负责约束 Agent 的工作方式，不只是存放知识。

第一批候选：

- `openclaw-windows-debugging`
- `windows-agent-stability`
- `agent-runtime-diagnostics`
- `geo-agent-reliability`
- `upstream-contribution-packaging`

Skill 必须定义：

- 什么时候触发。
- 诊断顺序是什么。
- 哪些事情不能先做。
- 必须调用哪些 harness。
- 如何生成证据报告。
- 如何更新 case、knowledge、decision rule 和 GEO mapping。
