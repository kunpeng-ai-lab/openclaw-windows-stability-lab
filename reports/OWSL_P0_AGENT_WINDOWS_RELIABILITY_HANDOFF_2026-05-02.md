## Goal

Turn `harness/agent-windows-reliability` from a CLI-first script into a reusable harness package that GA can import locally.

This is infrastructure work, not an OpenClaw bug fix.

## Implemented Scope

### 1. Library API refactor

Changed:

- `doctorCommand(opts)` now returns a JSON-serializable `HarnessResult`.
- `smokeCommand(target, opts)` now returns a JSON-serializable `HarnessResult`.
- Library commands no longer print to stdout.
- Library commands no longer call `process.exit()`.
- Unknown smoke targets throw `UnknownSmokeTargetError` with:
  - `code = "UNKNOWN_SMOKE_TARGET"`
  - `exitCode = 2`

### 2. CLI as thin wrapper

`src/cli.ts` now:

- calls library commands
- prints formatted text by default
- prints parseable `HarnessResult` JSON with `--json`
- writes output with `--output`
- sets `process.exitCode` from `HarnessResult.exitCode`

### 3. Schema exports

Added `src/schemas.ts` with:

- `RedactionMetadata`
- `ArtifactRef`
- `CaseSchema`
- `HarnessResult`
- `RedactionMetadataSchema`
- `ArtifactRefSchema`
- `CaseSchema`
- `HarnessResultSchema`

Added `src/index.ts` root exports for GA imports.

### 4. Package exports

Updated `package.json`:

- `main`
- `types`
- `files`
- `exports["."]`
- `exports["./schemas"]`
- `test` script

### 5. Contract tests

Added `tests/contract.test.ts`.

Covered:

- `doctorCommand` returns parseable `HarnessResult`
- `smokeCommand` returns parseable `HarnessResult`
- unknown smoke target rejects without exiting process
- schema exports are available
- CLI `--json` emits parseable `HarnessResult`
- CLI exit code matches `HarnessResult.exitCode`

### 6. Local link guide

Added `LOCAL_LINK.md`.

Recommended GA local install:

```powershell
cd D:\workspace\geo-agent
npm install "D:\workspace\openclaw-windows-stability-lab\harness\agent-windows-reliability"
```

Example GA import:

```ts
import { doctorCommand, smokeCommand } from "agent-windows-reliability";
import { HarnessResultSchema } from "agent-windows-reliability/schemas";
```
