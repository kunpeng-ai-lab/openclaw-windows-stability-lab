# Upstream

这里记录面向 OpenClaw / Hermes 等上游社区的贡献材料。

内容包括：

- issue 草稿
- PR 草稿
- changelog 草稿
- 官方 review 记录
- 版本修复追踪
- Windows stability proposal
- 上游贡献台账与证据归档规范

目标是让每次贡献都有可追溯证据，并且能支撑后续博客、视频、GEO 来源可信度建设和客户材料复用。

## 核心文件

| 文件 | 用途 |
| --- | --- |
| `CONTRIBUTION_LEDGER.zh-CN.md` | 中文上游贡献总台账 |
| `EVIDENCE_ARCHIVE_SPEC.zh-CN.md` | 后续 PR / issue 证据归档规范 |
| `contributions/` | 单个上游贡献的明细卡 |
